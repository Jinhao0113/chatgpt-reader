# ChatGPT Reader

当前版本：**1.5.2**。阅读助手改为浏览器原生 Side Panel。浏览器直接把 ChatGPT 网页和阅读助手分配到两个相邻区域，原网页的右边界位于侧栏左侧，正文、顶部栏和输入框按缩小后的网页窗口重新排版。扩展不再用悬浮阅读面板覆盖网页，也不再强制修改网页 body 的尺寸或位置。四个功能标签使用同一个原生侧栏，切换时不会改变宽度；侧栏宽度可通过浏览器分隔线调整。

为 `https://chatgpt.com` 网页对话提供回答目录、选文侧边提问、PDF 导出和阅读工具。原生 JavaScript，Manifest V3，无需编译或安装 npm 依赖。适用于桌面版 Chrome / Edge 120 及以上版本。

## 下载

从 [GitHub Releases](https://github.com/Jinhao0113/chatgpt-reader/releases/latest) 下载最新版安装包，或查看 [源码仓库](https://github.com/Jinhao0113/chatgpt-reader)。

## 安装（约一分钟）

1. 解压 `chatgpt-reader.zip`，保留解压后的整个 `chatgpt-reader` 文件夹。不要只选择 `manifest.json`。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 打开右上角「开发者模式」，点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的 `chatgpt-reader` 文件夹。
4. 打开或刷新 ChatGPT 网页。点击右下角阅读图标或工具栏扩展图标，打开浏览器原生侧栏。关闭时点击浏览器侧栏标题处的 ×。

安装后请保留扩展文件夹。更新代码后，在扩展管理页面点击刷新，再刷新已打开的 ChatGPT 网页。

升级时，用新版文件覆盖**原来加载的扩展文件夹**，再按上面的顺序刷新。不需要卸载扩展，已有本地收藏和侧栏记录会保留。

## 使用

### 实时回答目录

点击阅读图标打开浏览器右侧面板，标题按层级生成目录，点击即可跳转。无标题的回答会按简短加粗小标题或段落生成导航。滚动时，默认跟随当前可见回答；从下拉列表手动选择某条回答后，暂停自动跟随，可在「阅读」中重新启用。

目录覆盖当前网页已加载的回答。阅读时间按每分钟约 550 字估算。阅读进度表示当前回答在视口中的大致位置。

目录点击会在原网页重新解析最新位置，支持回答更新后的目录、重复标题、公式标题和按段落生成的目录。跳转后核对实际位置，网页重新排版时重新定位；目标尚未加载或对话已切换时提示并刷新目录。

### 历史聊天

从 ChatGPT 左侧聊天记录打开任意旧对话，即可查看已经加载的回答目录、搜索、收藏、选文追问和导出。不需要重新提问。向上滚动加载更早的消息时，回答数量和下拉列表会自动更新；也可点击「正在阅读」右侧的重新扫描按钮。

兼容带消息角色属性的页面、只提供「ChatGPT 说 / 你说」标题的页面，以及旧版 Markdown 回答。切换聊天会切换对应的收藏和侧栏记录。扩展读取当前网页显示的消息，不会批量下载账号中尚未打开的聊天。

### 选文侧边提问（无需 API Key）

追问界面采用接近 ChatGPT 的对话排版：提问显示为右侧气泡，回答直接排版在聊天区域，引用以可展开的片段显示。底部为自动增高的圆角输入框，圆形箭头发送、生成时切换为停止按钮。Enter 发送，Shift + Enter 换行，并避免中文输入法确认候选词时误发送。选中的原文显示在输入框上方，快捷模板只填入草稿。回答下方可复制全文；向上阅读长对话时，可点击「回到最新回答」。新对话、打开后台和 PDF 导出收进顶部工具栏。

1.2.1 适配当前网页版的 ProseMirror 输入框与「发送」按钮，同时保留旧版输入框支持。连接错误只显示一次，并在错误旁提供「打开后台对话」。尚未尝试提交的问题可点击「重试此问题」，保留原引用和问题；已尝试提交的任务先到后台确认，避免重复发送。升级时会整理 1.2.0 保存的重复错误记录。

1. 在一条 ChatGPT 回答中选中文字；浮动菜单提供「询问 ChatGPT」与「收藏」。
2. 点击「询问 ChatGPT」，侧栏出现引用、问题输入框和快捷提问模板。
3. 输入问题并点击「发送」；也可直接发送默认的解释请求。
4. 扩展在同一浏览器中创建**一个普通的独立 ChatGPT 标签页**，复用网页版登录，通过输入框发送问题，把生成的回答同步到侧栏。后续追问继续使用这个对话。

独立标签页会出现在浏览器标签栏；请保持打开。侧边问题和回答也会出现在 ChatGPT 的历史记录中，使用网页版账号当前的模型和额度。不会完整继承原对话历史、项目上下文、自定义 GPT、附件或模型设置。默认只发送选文和问题；「附带原回答」选项额外发送该回答前 6,000 字。

「解释一下 / 举个例子 / 提炼要点」仅填入问题，点击「发送」才提交。侧栏有「停止」和「打开后台对话」；「开始新的侧边对话」清空本地侧栏记录并在下次提问新建后台对话，原 ChatGPT 历史和旧标签页保留。

这是一种**网页界面适配**，没有调用或逆向 ChatGPT 私有接口，没有读取 Cookie 或登录令牌。网页改版、登录提示、验证码、额度限制、后台标签冻结或浏览器节流可能导致同步延迟或失败。此时打开后台对话检查提示；必要时手动发送已经填入的问题。扩展不会自动重复提交。最长等待约 5 分钟，超时会保留已经同步的部分内容。网页适配相关选择器集中在 `bridge.js` 与 `shared.js`，方便维护。

选区必须位于同一条回答内；最大引用长度为 12,000 字。侧栏单次发送总长度上限为 24,000 字。切换原网页对话后会切换对应的本地侧栏记录。

### PDF / Markdown

在面板底部选择「当前回答」「整个对话（当前已加载）」或「侧边对话」。侧边对话也可直接点击「追问」标签右上方的下载图标导出 PDF。

PDF：点击「导出 PDF」打开独立排版预览，再点击「打印 / 保存 PDF」，在浏览器的打印目标中选「另存为 PDF」。支持 A4 排版、目录、代码换行、表格重复表头、中文和原生 MathML 公式。需要更干净的页面时，关闭打印对话框中的「页眉和页脚」。PDF 由浏览器打印引擎生成，需要手动选择保存位置。

Markdown：普通回答直接下载 `.md` 文件，保留标题、列表、代码、链接和表格。包含 SVG / Canvas 图示时，下载 `-Markdown.zip`，其中包括 `.md` 文件和 `assets/` 图示资源；解压并保持两者相对位置即可阅读。SVG 保留矢量图，Canvas 保存为 PNG。公式以 MathML 保留，能否显示取决于 Markdown 阅读器。

#### Intelligent UI（1.5.0）

兼容当前网页的 `data-dil-message-id` / `data-d-component` 原生渲染内容。导出会从原网页读取当前回答，保留同一回答中的普通文字和 Intelligent UI 内容；支持已经加载的历史回答。

- PDF 使用白底和深色正文、坐标轴及标注，保留当前可见卡片、表格、MathML、SVG 图示及可读取的 Canvas。支持直接 SVG 和 URL 编码 / Base64 内嵌 SVG 图片；原始插图保留自身配色。
- 输入、滑块、选择框、复选框和按钮的当前状态转换成静态文字。密码、隐藏输入和文件选择器不导出。
- 状态 / 内联图标保持小尺寸；图表按比例缩放且居中，普通图片不放大、宽度最多 145 mm，长图高度最多 160 mm。图片卡片随内容增高，图注和来源位于图下，移除打开 / 收藏图片按钮，后续正文不会覆盖图片。
- 表格按纸张宽度重新分配列宽，长中文、英文和链接允许换行，保留所有单元格和重复表头。
- Markdown 把卡片展开为文字，把图示放入 ZIP 内的资源文件。
- 新的侧边回答完成后同步图示和参数，也可导出。侧栏保存的是回答完成或停止时的状态；需要导出后台对话中后来调整的图表时，请在该后台原对话使用阅读助手导出。

导出结果是静态快照，不包含可运行的交互脚本。已展开的详情保留内容，折叠详情仅保留标题。生成中导出会注明内容尚未完成。

导出整个对话前，先向上滚动，确保需要的历史消息已加载。图片能否导出取决于原链接是否仍可访问。无法读取的 iframe、受跨域限制的 Canvas 和音视频会附上说明；隐藏的 Intelligent UI 执行沙箱不会导出。不读取尚未显示的附件内容，也不自动展开卡片。复杂布局、Canvas 中未保留的 WebGL 帧以及外部嵌入组件不保证完整还原。单次导出过大时，请缩小到当前回答。

## 补充的阅读功能

- 全对话文字搜索、匹配高亮、上一个 / 下一个定位（最多 300 处）。
- 段落收藏和原文定位，刷新后仍保留；可导出 Markdown 收藏笔记。
- 当前回答阅读进度和预计阅读时间。
- 阅读排版：14–22 px 字号、1.4–2.4 倍行距、代码自动换行。
- 明亮 / 深色 / 跟随 ChatGPT 的面板主题。
- `⌘ / Ctrl + Shift + L` 打开或关闭面板；侧栏 `Enter` 发送、`Shift + Enter` 换行（兼容 `⌘ / Ctrl + Enter`）；`Esc` 收起。
- 支持键盘操作、可见焦点、减少动态效果的系统偏好；面板使用浏览器独立侧栏，为原网页保留阅读与输入空间。

## 数据和权限

- 仅在 `https://chatgpt.com/*` 注入脚本，申请 `storage`、`alarms`、`sidePanel` 权限及该站点访问权限。`sidePanel` 用于把阅读面板放入浏览器原生侧栏，不会增加其他站点的读取权限。
- 偏好、收藏和侧边文字记录保存在浏览器的 `chrome.storage.local`，不会上传到开发者服务器，也不启用云同步。
- 后台任务状态和 PDF 预览临时数据保存在 `chrome.storage.session`，浏览器重启后清除。预览数据约 30 分钟过期。
- 不包含分析统计、广告、第三方 SDK、远程执行代码或 API Key。
- 只有点击「发送」或使用发送快捷键时，选文 / 可选上下文 / 问题才作为新消息发送给 ChatGPT。生成答案中的图片和导出预览中的原图片仍可能从原图地址加载。
- 删除扩展会删除本地收藏和侧边记录；建议先导出笔记。ChatGPT 中已经保存的对话仍在网页版历史中。

## 文件结构

```
manifest.json   扩展入口、权限与快捷键
background.js   标签页路由、任务状态、超时和打印预览
bridge.js       后台 ChatGPT 输入与回答同步适配
content.js      原生侧栏内的阅读功能界面
chat.css        追问聊天界面的排版与输入样式
native-panel.js 原生侧栏与原网页之间的数据同步
page-agent.js   网页消息提取、选文菜单和定位
sidepanel.html  浏览器原生侧栏入口
shared.js       回答提取、目录、安全静态 HTML / SVG 与 Markdown
rich-export.js  Intelligent UI 布局、图示与控件状态快照
zip.js          Markdown 与图片资源的本地 ZIP 打包
page.css        主网页阅读排版与选文高亮
print.*        PDF 预览和打印样式
icons/         本地扩展图标
```
